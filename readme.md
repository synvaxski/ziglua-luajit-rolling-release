# Ziglua - LuaJIT Rolling Release
 
A fork of [natecraddock/ziglua](https://github.com/natecraddock/ziglua) (Zig bindings for the Lua C API) that tracks the latest development commit of [LuaJIT](https://luajit.org) (`v2.1` branch, "rolling release").

⚠️ Not recommended for stability-critical environments

This fork follows LuaJIT's development branch, which has no stable release tags, and it is updated automatically. Because of this:

The LuaJIT version can change from week to week without notice.
Upstream changes in LuaJIT or ziglua can break the build or change behavior.
It is maintained on a best-effort basis, with no guarantees of stability or support.

If you need stability, please use the original project instead.
